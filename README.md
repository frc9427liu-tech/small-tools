# 分貨小幫手

貼上 LINE 記事本的訂單,自動產生「照商品分」與「照客人對」兩份核對表,兩邊打勾連動,防止團購分貨時分錯。

## 為什麼做
團購主分貨常混用兩種順序(一次發一種商品給所有人 / 一個客人湊齊),進度只存在腦袋裡,中途切換就漏發或重複。分錯高單價商品(例如香水)要賠兩邊。

## 設計決定
- 同一份資料、兩種檢視、**共用打勾狀態**:進度永遠在畫面上。
- **專注模式**:一次只顯示一種商品,大字,看不到別的品名。
- **💎貴重商品**勾選要二次確認;**⚠️容易拿錯**由使用者自己標,跳紅字提醒。
- 不用安裝、不用註冊、免費:資料只存在自己的瀏覽器。

## 使用
貼上訂單:第一行商品名,下面每行「客人 數量」,空行換下一個商品。數量可寫 `2`、`x2`、`+2`、`×2`、`2個`。

## 技術
單一 HTML 檔,純 JavaScript,進度存 localStorage。範例資料皆為虛構。
